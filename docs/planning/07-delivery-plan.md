# 7. 开发任务、依赖、交付物与验收

本轮只排任务，不开始实现。任务完成的定义是验收标准通过，而不是「页面能打开」。

带 Q 编号的阻塞项见第 9 篇。阻塞项未答复时，只允许做不依赖该答案的任务；不允许用临时常数假装已经确认。

## 7.1 依赖关系

```text
T0 审查并确认阻塞项
  ├─ 2026-10-16 已确认：Q1–Q8、Q10、Q10b、Q12、Q15、Q2b、Q3b
  ├─ 真实豆包调用仍需要环境中的 API Key；没有密钥时只用夹具
  └─ 不因为没有小时数和上传上限而停住。未配置就按「不按时间失效」和「拒绝上传」实现

T1 工程骨架
  └─ T2 数据模型
       ├─ T3 认证与权限骨架
       │    └─ T4 客户、项目、成员
       │         └─ T5 素材上传
       ├─ T6 分析任务（文本）
       ├─ T8 模块模型与渲染
       ├─ T11 成本报价录入
       └─ T12 任务录入

T6 + T8 ──▸ T7 随生成任务解析 web_search 并转存
T7 + T8 ──▸ T9 草稿生成与模块编辑
T9 + T11 ──▸ T10 预览中的报价投影、发布快照
T10 ──▸ T13 审核与分享
T12 可与 T10 并行，但 T13 送审页要能看到任务状态
T3 ──▸ T14 审计（贯穿 T4 之后每个写接口补齐）
T10 + T13 ──▸ T15 端到端验收
T1 ──▸ T16 部署与回滚演练（可与功能并行准备，演练放在 T15 前）
```

T6 在供应商未定前，交付「适配器 + 固定夹具」，不交付生产密钥接入。

## 7.2 任务

### T0 确认阻塞项

- 依赖：无。
- 交付物：第 9 篇问题的书面答复，以及被推翻的假设列表（R-A*、D*）。
- 验收：两批答复已写入各篇。没有伪造的利润率、上传兆字节和会话小时数。模型 ID 固定为 `doubao-seed-evolving`。
- 说明：T0 的产品问题已经够开始 T1。本轮用户只补充规则，实现仍等下一轮明确开工。没有 API Key 时不把真实调用算作通过。

### T1 工程骨架

- 依赖：无。
- 交付物：TypeScript 应用入口、worker 入口、PostgreSQL、Redis、MinIO 的 Compose、空的健康检查、`.env.example`、基本 lint 与测试命令。
- 现状：骨架在 `cursor/app-foundation-aff7`。Prisma 仍无业务表。登录页只说明认证未接入。格式化命令不改写 `docs/planning`。
- 验收：本地一条命令能启动依赖；web 与 worker 进程能启动；仓库中没有密钥；`src/server` 不被客户端组件引用（用工程约束检查）。
- 不做：业务页面。

### T2 数据模型

- 依赖：T1。
- 交付物：第 5 篇各表的迁移。状态和角色枚举若 T0 未完成，先只建 T0 已确认的子集，或使用文档中的假设并在迁移说明里标注「待 T0 复核」。更稳妥的做法是 T0 完成后再合并 T2。
- 验收：迁移可在空库执行；金额列为 numeric；快照表没有更新业务内容的设计（没有把草稿和快照合成一行反复改）。
- 不做：种子报价科目。

### T3 认证与权限骨架

- 依赖：T2。角色和隔离按 Q4，开通方式按 Q12。会话按 Q15：未配置时长则不按时间失效，未配置锁定次数则不锁定。
- 交付物：管理员开通本地口令、登录、退出、停用即失效、按角色和财务开关拒绝的检查函数、按项目成员隔离。
- 验收：无会话访问内部 API 被拒绝；停用后旧 Cookie 被拒绝；无财务可见时成本、报价和利润接口被拒绝；非成员且非管理员看不见项目；客户路由不使用这套会话。
- 不做：公开注册、企业身份源、多因素认证。

### T4 客户与项目

- 依赖：T3。
- 交付物：客户档案、项目、需求正文、成员、归档、项目列表与概览页。
- 验收：符合 M3、M4、M5。隔离规则与 Q4 结论一致，并有一条反例测试（不该看见的人看不见）。

### T5 素材上传

- 依赖：T4。具体类型和大小仍可能为空。
- 交付物：上传、列表、预览或下载、删除保护的接口和页面。
- 验收：符合 M6 与 R15。限制未配置时拒绝上传；配置之后超限拒绝；路径不由文件名决定；对象不可被公开列举。

### T6 需求分析

- 依赖：T2、T5。素材出域已允许。模型固定为火山方舟 `doubao-seed-evolving`。
- 交付物：方舟 Responses 适配器、分析任务、结构校验、分析页的改正与确认。
- 验收：符合 M7、M8 与 R8。校验失败不写当前分析。没有 API Key 时任务失败且不改分析。请求使用该 Model ID，不改派其他模型。CI 不访问真实方舟。
- 不做：让模型填写对外金额。

### T7 搜索与选用

- 依赖：T6 的同一套方舟调用。搜索不单独选供应商。
- 交付物：从 `web_search` 结果提取来源、写入模块引用、转存工具返回的地址、手工补链、移除匹配。
- 验收：符合 M9–M12、R9、R17。不存在第二套搜索 API 客户端。工具结果之外的媒体地址被拒绝。没有可下载地址时保留文字来源。限制未配置时转存失败。授权状态默认 unknown。CI 用夹具模拟工具结果，不抓取外网。

### T8 模块模型与渲染器

- 依赖：T2。可与 T6、T7 并行。
- 交付物：HTML/CSS 模板、导出前的消毒、报价与素材节点重写。七类已确认模块加上封面与需求理解。
- 验收：给定夹具工程，导出包含对应章节；夹带成本字段不出现；脚本被去掉；报价章节只含对客行。
- 不做：视觉定稿。先使用可读的专业排版，品牌色等 Q16。

### T9 编辑与草稿生成

- 依赖：T6、T7、T8。
- 交付物：GrapesJS 编辑页、模板 block、素材替换、单模块重生成后的确认写回、乐观锁。后台其余页面用 shadcn/ui。
- 验收：符合 M13–M15；已有草稿不会被生成任务自动覆盖；冲突保存失败；替换时只能选已转存结果或本项目客户素材；报价数字不能在画布里改。

### T10 预览与发布

- 依赖：T9、T11 的报价读取（报价可以为空）。
- 交付物：预览、发布、快照列表、冻结的 HTML/CSS，以及由该快照打印的 PDF。
- 验收：符合 M16、M17、M25。发布后改草稿，快照 HTML 不变。PDF 与该 HTML 同源。发布失败不出现可交付快照。

### T11 成本与报价

- 依赖：T2、T3。
- 交付物：成本项与报价项的录入、对客可见开关、利润接口。
- 验收：符合 M19–M21 与 R11。利润接口返回未配置，不返回百分比；无财务可见为 403；分享渲染测试不含成本备注。
- 不做：税率、折扣审批、合同价、利润公式。

### T12 执行任务

- 依赖：T4。与提案的关联在快照存在后补上 snapshot_id。
- 交付物：手工任务的新增、修改、确认与取消。
- 验收：符合 M22 与 R12。没有行业模板接口，也没有自动草案接口。客户 HTML 不含任务。

### T13 审核与交付

- 依赖：T10、T3。细则按 Q7、Q8。
- 交付物：送审、单人通过或退回、分享、撤销、客户阅读页。
- 验收：符合 M18、M23、R6、R13、R14。未通过不能交付。一名审核人通过即可交付该快照。草稿变化后旧通过记录不能交付新内容。旧链接在新版本发布后仍打开旧 HTML。撤销后阅读页 404。阅读页响应不含内部字段。不因归档自动撤销。

### T14 审计

- 依赖：T3，并在 T4–T13 的写操作上补调用。
- 交付物：审计表写入与项目内查询。
- 验收：符合 M24；抽查发布、退回、改报价、停用账号四条记录包含操作者、时间、对象；记录中无令牌明文和密钥。

### T15 主路径验收

- 依赖：T5–T14。
- 交付物：第 8 篇所列端到端用例在测试环境通过的记录。
- 验收：用测试夹具走通第 3 篇主流程；并至少覆盖：搜索为空仍能发布、模型返回非法 JSON、审核退回、交付后修改必须新版本、无财务权限、分享页隔离。
- 供应商若仍不可用，T15 对分析与搜索使用夹具，不把夹具称为已上线的全网搜索。

### T16 部署与回滚演练

- 依赖：T1；完整演练依赖 T15 的构建产物。
- 交付物：按第 8 篇部署的说明、环境清单、一次在预发环境的备份与回滚记录。
- 验收：回滚应用版本后，已发布快照仍可打开；失败的迁移不会部分暴露给流量（见第 8 篇）。

## 7.3 建议的实现顺序

1. 模型、搜索方式、会话和上传规则已经够开始 T1。本轮仍不写代码，等明确开工。
2. T8 与 T6、T7 一起做。渲染器把模块变成 HTML；豆包只生成模块内容和搜索引用。
3. T3、T4、T5 按已确认的角色、隔离、本地口令实现。上传限制未配置则拒绝。会话未配置时长则不按时间失效。
4. T11、T12 用手工数据打通。利润保持未配置，这是验收条件。
5. T6、T7 用夹具跑通 web_search 结果解析和转存。有 API Key 后再打真实方舟。
6. T9、T10、T13、T14。审核按单人，链接按可撤销且旧链接留在旧快照。
7. T15、T16。

不建议的顺序：先做登录页和视觉，最后才做模块渲染。那会把风险留在已确认的核心交付物上。
