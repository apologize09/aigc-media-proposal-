# 10. HTML 可视化编辑器基础方案

可视化编辑的基础是 GrapesJS。后台其余页面使用 Next.js、React、TypeScript、Tailwind CSS 和 shadcn/ui。提案本身使用 HTML/CSS 模板，不使用 shadcn 组件。

客户主交付仍是 HTML。PDF 从同一份已发布 HTML/CSS 打印，不另做一版版式。

## 10.1 三层怎么分工

```text
HTML/CSS 模板          每种模块的初始结构
        │
豆包适配层             填文本、写入搜索到的素材引用
        │
GrapesJS 工程 JSON     草稿。组件、样式、traits
        │
导出 HTML + CSS        消毒后发布成快照
        │
无头浏览器             把该快照打成 PDF
```

GrapesJS 只在提案编辑页加载，并且关闭服务端渲染。它不进入客户链接，也不进入后台的列表和表单。

草稿源数据是 GrapesJS 工程 JSON，不是一整个可随意粘贴的 HTML 字符串。发布物是导出的 HTML 与 CSS。旧链接读取发布时的文件，不重新打开 GrapesJS。

## 10.2 模板

模板放在 `src/proposal/templates/`。基础方案有一套中性样式，外加这些片段：封面、需求理解、创意、视觉风格、案例、分镜参考、制作流程、报价、排期。品牌色和 logo 等 Q16，模板里不写公司名。

每个片段注册成一个 GrapesJS block。豆包生成内容时，适配层把文本和素材 ID 填进这些片段，再交给编辑器。编辑在模板上改字、换图、调整块的顺序。

整页源码模式不打开。需要改结构时，使用已注册的 block，而不是粘贴外部 HTML。

## 10.3 必须锁住的 traits

自由编辑不能把报价和素材变成两套数据。

| 内容 | 在 GrapesJS 中 | 发布时 |
| --- | --- | --- |
| 报价金额、数量 | 组件不可在画布里改数字。traits 只保存报价行 ID | 用报价表重写这些节点。未标对客可见的行不导出 |
| 图片和视频 | 素材管理只列出本项目客户素材和已转存副本。traits 保存素材 ID | 用素材表写入该快照可用的地址。不导出 base64，不用方舟临时地址 |
| 来源 | 来源名称和地址可改，并显示在客户 HTML 中 | 授权状态留在 traits，不写进客户 HTML |
| 成本、利润、任务 | 不注册成组件，适配层也不允许输出这些字段 | 导出结果里不得出现 |

转存未成功的媒体可以留在编辑器里并显示原因，但不能进入已发布 HTML 或 PDF。只有标题和来源的创意参考可以发布。

没有对客报价时，报价块显示「尚未填写对客报价」，不显示 0 元。

## 10.4 统一模型适配层

业务代码只依赖一个接口：分析需求、生成提案初稿、重新生成一个 block。本期唯一实现是火山方舟上的 `doubao-seed-evolving`，通过 Responses API 调用，并在同一次调用里使用 `web_search`。

适配层把工具返回的地址整理成内部的搜索记录，再交给转存。模型正文里出现、但工具结果里没有的媒体地址直接丢弃。

不在这层接入第二家模型，也不把方舟响应原样存进提案表。没有 API Key 时，这三个操作失败并说明未配置。

重新生成一个 block 时，新结果先并排显示。采用后才替换该 block。放弃或失败时，工程 JSON 不变。报价 block 不提供重新生成。

## 10.5 保存、预览、发布、PDF

编辑过程中的工程 JSON 在保存时提交，并带上 `updated_at`。别人已改过同一草稿时，本次保存被拒绝，浏览器里未提交的修改还留着。

预览使用即将导出的 HTML 与 CSS，而不是再做一套 React 版式。发布把消毒后的 HTML、CSS 和当时的工程 JSON 一起冻结。客户链接只带 HTML 与 CSS。

PDF 由 worker 里的无头浏览器打开这份已发布 HTML 打印。它与该版本 HTML 同源。内部可以下载 PDF。客户主链接仍然打开 HTML。不因为导出 PDF 而改写旧快照。

导出前去掉脚本、事件属性和 `javascript:` 链接。

## 10.6 后台界面与编辑器的边界

| 区域 | 技术 |
| --- | --- |
| 登录、项目列表、需求、报价、任务、审核 | Next.js + React + TypeScript，Tailwind CSS，shadcn/ui |
| 提案画布 | GrapesJS |
| 提案版式 | HTML/CSS 模板 |
| 数据 | PostgreSQL + Prisma |
| 部署 | Docker Compose，Nginx 作为唯一公网入口 |

shadcn 的按钮和对话框可以包住编辑器页面的保存、发布和导出。提案内部的标题、案例和分镜不用 shadcn 重做一遍。

## 10.7 仍然不做

- 不把 GrapesJS 的整页源码模式当作基础编辑方式。
- 不在模板确认前做自由换肤。块内文字和图片可以改。
- 不把 PDF 做成第二套排版或客户的主阅读页。
- 不在适配层里接入豆包以外的模型。
- 不在编辑器里改成本、利润和任务。
- 不做实时多人光标。保存仍用乐观锁。
