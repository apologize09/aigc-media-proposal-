# 6. 登录、权限、隔离与密钥

角色、隔离、账号来源、模型和搜索方式已确认。会话不写死小时数。

## 6.1 登录认证

已确认的使用方式是内部 Web 系统，因此：

- 不提供公开注册、不提供「试用账号」入口。
- 账号由管理员开通，使用本地口令（Q12）。不接企业微信、飞书或 LDAP。管理员设定初始口令；系统不提供自助注册。
- 口令只存哈希（argon2id 或 bcrypt，实现时选一种并固定参数）。
- 登录成功后发会话标识。Cookie：`HttpOnly`、`Secure`、`SameSite=Lax`。会话记录存数据库，便于停用时作废。
- 退出删除服务端会话。管理员停用用户时删除该用户全部会话。
- 登录失败返回统一错误，不区分「无此邮箱」和「口令错误」。
- Q15 已确认不写死小时数，也不写死锁定次数。`AUTH_SESSION_TTL_HOURS` 未配置时，会话不因时间结束；用户退出或账号被停用后会话失效。环境变量若以后写入数字，才按该数字失效。`AUTH_LOCKOUT_THRESHOLD` 未配置时不做锁定。两处都不在代码里放 8 小时或 5 次这类常数。

MVP 不做多因素认证。

## 6.2 权限

### 已确认的角色（Q4）

| 能力 | 管理员 | 方案编辑 | 审核人 |
| --- | --- | --- | --- |
| 开通和停用账号 | 是 | 否 | 否 |
| 建项目、改需求、上传素材 | 是 | 是 | 否 |
| 分析、搜索、编辑提案、维护任务 | 是 | 是 | 否 |
| 填写成本与报价 | 仅当同时具备财务可见 | 仅当同时具备财务可见 | 否 |
| 查看利润 | 仅当具备财务可见 | 仅当具备财务可见 | 否 |
| 送审 | 是 | 是 | 否 |
| 通过或退回 | 是 | 否 | 是 |
| 创建或撤销交付链接 | 是 | 是 | 否 |
| 查看审计 | 是 | 否 | 否 |

本次没有要求方案编辑回避自己送审的快照。同一人可以既是方案编辑又是审核人，并审自己送出的快照。

财务可见是用户上的单独开关 `finance_access`，不是第四种角色。没有该开关的用户：

- 成本与报价 API 返回 403。
- 提案里仍然能看到已标记对客可见的报价模块，因为那是客户可见内容，编辑需要预览。
- 利润 API 返回 403。利润即使对有权限的人，本期也只返回未配置。

### 强制规则（与角色名无关）

- 所有内部 API 默认拒绝，再按能力放行。
- 客户令牌不能访问 `/api/*`。
- 分享页的数据访问函数只接受 snapshot id，并且只读 html 对象和该快照允许的公开资源。
- 停用用户立即失去内部权限，历史 `created_by` 保留。

## 6.3 数据隔离

单公司、单库（R-A6）。隔离边界如下。

| 边界 | 要求 |
| --- | --- |
| 客户与客户之间 | 客户 A 的分享令牌不能读出客户 B 的快照、素材或报价 |
| 草稿与已交付 | 令牌只解析到 delivery 所绑定的快照 |
| 内部与客户 | 成本、利润、任务、分析 payload、未选用候选、内部备注、审计、操作者姓名不进入分享 HTML 和公开 API |
| 项目与项目 | 已确认按参与人隔离。管理员可见全部。其他用户看不见未参与的项目列表、详情、素材和报价 |
| 模型供应商 | 已确认素材可以出域，且只发往火山方舟上的 `doubao-seed-evolving`。主机固定为方舟配置的地址。未配置 API Key 时任务失败，不改用别的模型或搜索服务 |
| 日志 | 应用日志不打印令牌、口令、密钥、Cookie。客户正文可能敏感，日志只打 project id 和 job id |

对象存储桶禁止公开列举。客户上传文件通过应用做权限检查后，再发短期签名 URL，或由应用代理读取。签名 URL 的有效期使用分钟级，具体分钟数实现时取短值并写进配置，不把桶策略改成公共读。

分享页中的客户素材若必须显示，使用单独的公开资源票据，绑定 snapshot 与 asset，可随交付撤销而失效。不要把永久存储 URL 写进 HTML。

## 6.4 分享令牌

- 令牌使用密码学随机数，至少 256 bit，再编码。库存哈希（SHA-256 即可，令牌本身熵足够）。
- 创建接口的响应是唯一一次返回明文的地方。数据库和审计都不存明文。
- 校验失败统一为 404，避免用不同状态码探测令牌是否存在过。
- 支持撤销（Q8）。本次没有要求必须过期，也没有要求访问口令。链接在撤销前保持有效，并始终指向创建时的快照。归档项目不自动撤销链接。
- MVP 不增加第二套访问口令。

## 6.5 密钥与配置

| 项 | 放置位置 |
| --- | --- |
| 数据库连接串、Redis、对象存储密钥 | 环境变量或部署平台的密钥存储 |
| 模型 API 密钥、搜索 API 密钥 | 同上，只有 web 的服务端和 worker 读取 |
| 会话签名密钥 | 环境变量 `AUTH_SECRET` |
| 非机密配置（上传上限、模型名、供应商名称、分享默认有效期） | 环境变量。管理页只读展示「是否已配置」，不回显密钥 |
| 利润公式 | 确认后存数据库配置，不写在前端 |

禁止：

- 把密钥写进仓库、镜像层、前端包、审计 metadata、错误信息。
- 在管理页面提供「粘贴 API Key 保存到数据库」作为 MVP 方案。内部系统人数少，环境变量更不容易被页面越权读出。若以后必须在页面配置，再单独做加密存储和权限，不提前做。

本地开发使用 `.env`，且 `.env` 不入库。`.env.example` 只有键和空值。

## 6.6 内容安全

- 富文本和模型产出的文本都走渲染消毒。不允许脚本、事件属性和 `javascript:` 链接。
- 提案里的图片和视频使用已转存的副本或客户上传文件，不把未校验的 HTML 片段拼进页面。创意案例若只有网页而没有可转存的媒体文件，保存来源 URL 和标题，不内嵌该网页。
- 分享页响应头：`Content-Security-Policy` 限制脚本来源为 `'none'`（提案不需要业务脚本）；`X-Content-Type-Options: nosniff`；`Referrer-Policy: no-referrer`。若某一合法视频站点必须 iframe，把该站点加入框架白名单，白名单来自配置而不是来自模型输出。
- 上传校验扩展名与内容类型。`UPLOAD_MAX_BYTES` 或 `UPLOAD_ALLOWED_MIME` 未设置时拒绝上传（Q10）。不执行上传文件。具体数字仍未给出，不在代码里写一个默认兆字节。
- 文件下载使用附件或受控预览，不用用户提供的文件名拼服务器路径。
- 服务端请求搜索和模型时，只访问配置中的供应商主机。
- 转存已允许。下载时只使用 http 或 https，拒绝内网、链路本地和元数据地址，限制跳转次数、大小和超时。手工补链的转存走同一限制。不提供通用的「代用户打开任意网址」接口。

## 6.7 审计与保留

MVP 审计动作：登录成功可记最小记录（用户 id、时间、结果），另外必须记开通/停用、角色与财务开关变更、发布、送审、通过、退回、创建交付、撤销交付、报价与成本的变更。

变更类 metadata 记录字段名和快照 id，不记录整份客户脚本的前后文，以免审计表变成第二份不受控素材库。完整正文以提案快照为准。

日志和备份保留多久等 Q14。未确认前，不实现自动清除客户项目。

## 6.8 依赖与运维安全

- 生产关闭调试栈追踪给浏览器。
- 数据库和 Redis 不对公网开放，只在内部网络给 web 和 worker。
- 备份加密与访问权限沿用部署平台能力。备份里含客户素材和报价，与生产同级保护。
- 依赖漏洞扫描可以作为 CI 项，不引入额外安全产品平台。

Q14 和上传的具体数字仍会改变参数。已经固定的是：无公开注册、本地口令、客户令牌与内部会话分离、按项目隔离、只用豆包 Seed-Evolving 及其联网搜索、密钥不进仓库和浏览器、成本利润不进分享页、链接可撤销且不随新版本改指向、会话不写死小时数。
