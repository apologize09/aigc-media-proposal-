## 已确认事实（总览）

1. 建设方是一家做综合 AIGC 传媒业务的公司。公司法定名称、品牌和具体服务目录未提供。
2. 要直接做内部 Web 系统，而不是只交付一份离线文档或演示稿。
3. 目标输出有三块：完整方案、成本利润核算、执行任务拆解。
4. 给客户的完整方案是生成的 HTML，而且是核心交付物。
5. HTML 要能展示创意、案例、视觉风格、分镜参考、制作流程、报价和项目排期。它不能只是把一段 AI 文本套进网页模板。
6. 系统要根据客户需求和客户提供的素材，全网搜索相近的图片案例、视频案例和创意案例，并放进 HTML。
7. 后台按模块编辑这份 HTML：可改文案，可替换案例素材，可预览，可反复迭代。
8. 业务顺序：客户提交需求与素材 → AI 分析需求 → 全网搜索匹配案例 → 生成可视化 HTML 提案 → 后台模块化编辑 → 成本利润核算 → 生成执行任务 → 审核后交付客户。
9. 2026-10-16 第一批：客户只收链接；素材可以出域；网络案例可以转存；角色为管理员、方案编辑、审核人，另加财务可见开关，项目按参与人隔离；本期没有利润公式；不做行业模板，任务以手工为主；单人审核即可通过；交付链接可撤销，旧链接保持指向旧快照；上传限制未配置时拒绝上传；账号由管理员开通本地口令。
10. 2026-10-16 第二批：模型使用火山方舟豆包 Seed-Evolving，Model ID 为 `doubao-seed-evolving`。图片、视频和创意案例的搜索由该模型在生成提案内容时调用方舟联网搜索自行匹配，不另接一家搜索引擎。上传不写默认大小。会话不写死小时数；未配置时长时，会话不按时间失效，退出或停用账号即失效。

仍未确认的事项见 [09-open-questions.md](./09-open-questions.md)。火山方舟的 API Key 还没有提供。

## 本轮明确不做

- 不生成页面、接口、数据库迁移或脚手架代码。
- 不补造利润公式、税率、上传大小和会话小时数。
- 不把模型直接生成的整页 HTML 当作可编辑源数据。模块化编辑已经确认，搜索结果要进可替换的模块。
