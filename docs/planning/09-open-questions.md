## 9.1 已确认（2026-10-16）

| 编号 | 答复 | 写入规划后的规则 |
| --- | --- | --- |
| Q1 | 客户只收链接 | 客户无账号。审核通过后交付可撤销链接。客户批注留在第二阶段 |
| Q2 | 素材可以出域 | worker 可以把需求文本和素材二进制发给火山方舟上的 `doubao-seed-evolving`。API Key 仍由环境注入，规划不记录密钥 |
| Q3 | 可以转存 | 模型检索并匹配后，对工具实际返回的可下载地址做转存，保留来源。授权状态默认未知 |
| Q4 | 三种职责加财务开关，隔离 | 管理员、方案编辑、审核人。财务可见是开关，不是第四种角色。管理员看全部项目，其他人只看自己参与的项目。没有要求禁止自审 |
| Q5 | 暂无公式 | 不计算利润率，不预置税率、币种和费率。利润区显示未配置。金额只来自人工录入 |
| Q6 | 不做行业模板，任务以手工为主 | 不按业务类型生成模块模板或任务包。任务接口只有手工创建和确认 |
| Q7 | 单人审核 | 一名审核人通过即视为该快照通过。退回和再次通过都保留历史记录。不做会签 |
| Q8 | 可撤销；旧链接指向旧快照 | 撤销使该链接失效。新版本不改旧链接的指向。这次没有要求必须过期，也没有要求访问口令。归档不自动撤销 |
| Q10 | 未配置则拒绝上传；Q10b 不写默认上限 | `UPLOAD_MAX_BYTES` 或允许类型未设置时，上传和转存都拒绝。代码和示例配置都不写默认兆字节。具体数字保持为空 |
| Q12 | 管理员开通本地口令 | 无公开注册，不接企业身份源，不做多因素认证 |

## 9.2 2026-10-16 第二批

| 编号 | 答复 | 写入规划后的规则 |
| --- | --- | --- |
| Q2b | 模型供应商为 Doubao-Seed-Evolving 豆包大模型 | 只使用火山方舟 Model ID `doubao-seed-evolving`。调用走方舟 Responses API。不在代码里改派到别的模型 |
| Q3b | 可否由豆包在生成 HTML 时自行匹配并搜索素材 | 可以，并且就用这种方式，不另接搜索引擎。模型在生成提案模块时调用方舟联网搜索工具自行检索、自行挑选匹配结果。客户看到的 HTML 仍由模块渲染得出，不保存模型吐出的整页 HTML 作为源数据。只有工具返回的真实地址可以转存；模型编写的地址不算搜索结果 |
| Q10b | 不写默认上限 | 与 Q10 相同。未配置即拒绝，不增加默认值 |
| Q15 | 不写死小时数 | 不设置 8 小时或任何固定时长，也不设置固定锁定次数。`AUTH_SESSION_TTL_HOURS` 未配置时，会话不因时间结束，退出登录或停用账号后失效。以后若在环境变量里写入数字，才按该数字失效。锁定次数未配置则不做锁定 |

Q3b 的官方依据：火山方舟对 `doubao-seed-evolving` 提供统一 Model ID，并通过 Responses API 的 `web_search` 工具联网检索。文档把该工具描述为公开网页信息检索。它没有保证每次都返回可下载的视频文件。图片直搜是豆包搜索产品里的另一类接口，本期不另接。网页结果里如果带有图片或视频的真实地址，按转存规则保存；没有地址就只保留标题、摘要和来源，编辑可改用客户素材。
